# 美加大停电 · 失去的余度

2003 年美加大停电互动纪录片：视频章节、事故时间轴、四节点潮流实验、距离保护整定、调度员挑战与资料来源。

网站：https://zhongqilin18-sketch.github.io/blackout-2003/

## 运行与部署

纯静态网站，无后端、无登录、无分析追踪。GitHub Pages 使用 `main` 分支根目录。直接打开上述网址，点击播放或章节按钮即可观看。

本地预览：在本目录运行 `python -m http.server 8000`，访问 `http://localhost:8000`。HLS 需要 HTTP 服务；直接双击 HTML 时可手动选择本地 MP4，选择只对当前页面有效，不会上传该文件。

主要文件：

- `index.html`：网页样式、互动与播放器逻辑。
- `hls-v2/index.m3u8` 与 `hls-v2/seg*.ts`：原视频无重新编码封装的 HLS 点播资源。
- `vendor/hls.min.js`：hls.js 1.6.13，本地托管，Apache-2.0；许可证见同目录。
- `poster.jpg`：视频封面。

视频为 H.264/AAC，1280×720，总时长约176.884秒。封装命令：

```sh
ffmpeg -i input.mp4 -map 0:v:0 -map 0:a:0 -c copy -hls_time 6 -hls_playlist_type vod -hls_segment_filename "hls-v2/seg%03d.ts" hls-v2/index.m3u8
```

分段以原关键帧为边界，实际段长并非固定6秒。无损封装不意味着观看网络带宽可减少；较慢网络可能缓冲。支持原生 HLS 的浏览器优先使用原生播放，其余受支持浏览器使用本地 hls.js。

## 内容边界

史实与参考链接见页面末尾。潮流模型只计算稳态有功重分配，不模拟事故真实网架、无功、电压或暂态；动画插值不是暂态计算。N−1表针对初始电抗，且未设置线路容量，不据此判定安全。距离保护的动作区、延时、测试点，以及调度游戏的网络、限额、处置时间均为教学设定。
